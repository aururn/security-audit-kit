# 0004 Semgrep のルールをイメージに取り込む

- 状態: 採用
- 日付: 2026-09-30

## 背景

最初は、スキャンのたびに Semgrep のレジストリからルールを取得していた（`--config p/...`）。
このやり方には次の問題があった。

- 同じコミットでも、取得した日によって結果が変わる
- スキャンのたびにネットワークが必要になる
- **`p/nextjs` の中身が空（`rules: []`）だった。** 指定しているのに、実際には何も検査していないことに気づけなかった

## 決定

- イメージのビルド時に、ルールセット（default、owasp-top-ten、typescript、react、nodejsscan）を `/opt/semgrep-rules/` に取り込む
- 取り込んだルールセットが0件ならビルドを失敗させる。ルール数とハッシュの先頭をビルドログに出す
- `p/nextjs` は、空であるため外す
- ルールのファイルはリポジトリには置かない（Semgrep Rules License の再配布の条件を避け、ビルドした人が取得する形にする）

## 結果

- 同じイメージなら、いつ動かしても同じルールで検査する。スキャン時にネットワークは不要
- ルールを新しくするには、イメージを作り直す。取り込んだ日時は `/opt/semgrep-rules/FETCHED_AT` に残る
